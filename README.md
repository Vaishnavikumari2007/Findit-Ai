# 🔍 FindIt – AI Powered Lost & Found Platform

FindIt is a smart Lost & Found web application developed for **HackNite 2026**. It helps users report lost and found items and provides an intelligent matching system to connect owners with recovered belongings.

## 🚀 Problem Statement

Losing personal belongings such as wallets, ID cards, bags, keys, or electronic devices is a common problem. Existing lost and found systems are mostly manual, slow, and inefficient.

FindIt provides a digital platform where users can quickly report lost or found items and receive possible matches through a smart matching system.

---

## 💡 Solution

FindIt allows users to:

- Report Lost Items
- Report Found Items
- Search Lost & Found Records
- View Possible Matches
- Manage Reports through Dashboard
- Access the platform from any device

The platform aims to reduce the time required to reunite lost items with their rightful owners.
